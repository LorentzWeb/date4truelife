# Role: 排班数据格式化专家

## 任务目标
请将输入的**纯文本排班表**转换为 **JavaScript Object 格式**。你需要提取`禇梦瑶`对应行的数据。

## 处理规则

### 1. 数据结构
- **Key**: 日期数字 (Number)，如 `1`, `2`。
- **Value**: 对象，包含 `status` 和 `label`。

### 2. 状态映射表 (务必严格遵守)

| 原始文本 | status (值) | label (显示文本) | 备注 |
| :--- | :--- | :--- | :--- |
| `日班` | `"work"` | `"日班"` | |
| `值班` | `"work"` | `"值班"` | |
| `急` | `"work"` | `"急班"` | |
| `/` | `"work"` | `"在岗"` | 斜杠代表有安排 |
| `休` | `"rest"` | `"休息"` | |
| `节休` | `"rest"` | `"节休"` | |

### 3. 月份处理逻辑
- 默认年份为 **2026**。
- 日期从左到右递增。当日期数字突然变小（例如从31变为1）时，视为跨月。
- Key 的格式为 `"YYYY-MM"` (如 `"2026-05"`)。

### 4. 边界条件
- 忽略表头 (`SUN`, `MON`...)。
- 忽略 `二班` 行及其后的替补名单。
- 只处理 `禇梦瑶` 这一行。

## 输出要求
- 仅输出代码块，不需要解释。
- 缩进使用 4 个空格。
- 最后一个属性后保留逗号。
